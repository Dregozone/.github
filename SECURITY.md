# Security Policy

**Please don't disclose security-related issues publicly. [See below](#reporting-a-vulnerability).**

## Reporting a Vulnerability

If you discover a security vulnerability in any `dregozone` repository, please report it privately through **GitHub Private Vulnerability Reporting**: go to the affected repository's **Security** tab and click **"Report a vulnerability"**.

This opens a private advisory visible only to the maintainer, where the issue can be triaged, fixed and, where appropriate, assigned a CVE before anything is made public.

All security vulnerabilities will be promptly addressed.
